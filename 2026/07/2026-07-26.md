## 学んだこと一覧

### 構造体

* 構造体を使うことで、名前・身長・体重など、関連する複数のデータを一つのまとまりとして扱えることを学んだ。
* 配列が同じ型の値をまとめるものであるのに対し、構造体は異なる型の値もまとめられる。
* 構造体の型に付ける名前を「構造体タグ」、その型を使って宣言した変数を「構造体変数」と呼ぶ。
* `typedef`を使うことで、構造体変数を宣言するたびに `struct`と書く必要がなくなり、型名を簡潔に記述できる。

```c
typedef struct
{
    char name[64];  /* 名前 */
    double stature; /* 身長 */
    double weight;  /* 体重 */
} human;
```

* この書き方では構造体タグを付けず、`human`を型名として使用できる。

```c
human person;
```

* これまでは名前、身長、体重を別々の変数として管理していたが、構造体を使えば「一人分のデータ」としてまとめられるため、人数や項目が増えたときに管理しやすそうだと感じた。

### ファイルの読み書き

* `fopen`関数でファイルを開き、`fclose`関数で閉じる基本的な流れを学んだ。
* ファイルを開くときは、読み込みや書き込みなどの目的に応じてモード文字列を指定する。
* 開いたファイルはファイルポインタを通して操作する。
* `fscanf`関数を使い、テキストファイルから書式を指定してデータを読み込む方法を学んだ。
* テキストファイルは文字として内容を確認しやすいが、バイナリファイルはデータがそのまま保存されるため、通常のテキストエディタでは内容を確認しにくい。ただしバイナリファイルの方が一般的には高速で読み書きできるので一長一短だと思う。
* プログラムを終了してもデータを残せるようになるため、ファイル操作は構造体と組み合わせて使うことが多そうだと思った。

### 定数・マクロ・列挙型

* `const`を使い、プログラムの途中で変更しない値を定数として扱う方法を学んだ。
* `#define`を使って、コンパイル前に文字列や数値を置き換えるマクロを定義できることを学んだ。
* 引数を受け取る関数形式マクロも作れるが、通常の関数とは異なり、単純な文字列置換として処理される点に注意が必要である。
* `enum`を使うことで、互いに関連する整数定数に名前を付け、ひとまとまりにして管理できることを学んだ。
* `const`、`#define`、`enum`はどれも定数のように使えるが、それぞれ仕組みや用途が異なるため、使い分けを理解する必要があると感じた。

### 動的メモリ確保

* `malloc`関数を使うことで、プログラムの実行中に必要な大きさのメモリ領域を確保できることを学んだ。
* 確保したメモリ領域が不要になったら、`free`関数を使って解放する必要がある。
* `realloc`関数を使うことで、すでに確保したメモリ領域の大きさを変更できる。
* 通常の配列は宣言時に要素数を決めるが、動的メモリ確保を使えば、実行時の状況に応じて必要な要素数を決められる。
* 便利な反面、メモリの解放忘れや範囲外へのアクセスなど、自分で管理しなければならない部分が増えるため、これまでの配列より扱いが難しいと感じた。
* Valgrindついて少し学んだ。これでメモリリークをチェックすることでリスクを低減出来ることを学んだ。
