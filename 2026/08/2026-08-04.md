# 2026年8月4日

## やったこと
- Hyper-V上のUbuntu Server 2台で、SSH・UFW・Nginxを使った通信確認と障害再現を行った。

## 確認できたこと
- LAB-PRIVATEのみでVM間通信できた
- UFW遮断時はHTTP接続がタイムアウトした
- Nginx停止時は即座に接続失敗した
- Nginx復旧後はHTTP 200 OKを確認した
- access.logとjournalctlで通信・サービス履歴を確認した

## つまずいたこと
- 少しコマンドが長くなってきたせいか、些細なタイプミスでエラーが出やすくなり、エラー原因を探す手間がかかっている。

## 次回

## 番外編　使ったコマンドなど
```text
ネットワーク確認
ip addr show eth1
ip route

サービス確認
sudo systemctl status nginx --no-pager
sudo systemctl stop nginx
sudo systemctl start nginx

ポート確認
sudo ss -lntp

ログ確認
sudo journalctl -u nginx --since "15 minutes ago" --no-pager
sudo tail -n 20 /var/log/nginx/access.log
```
