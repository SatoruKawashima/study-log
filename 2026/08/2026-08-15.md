## 今日やったこと

### Nginxのアクセスログをgrepで絞り込んだ

Nginxの`access.log`に対して`grep`を使用し、HTTPステータスコードが404だったログだけを抽出する練習をした。

さらに、抽出したログをアクセス元のIPアドレスで絞り込んだ。

複数の条件で絞り込む際には、パイプ`|`を利用して、左側のコマンドの出力を右側のコマンドへ渡した。

```bash
grep '10.77.0.20' /var/log/nginx/access.log | grep ' 404 '
```

また、`grep -c`を使用し、条件に一致したログが何件存在するかを数えた。

---

### awk、sort、uniqを使ってHTTPステータスコードを集計した

`awk`を使用して、Nginxのアクセスログから空白区切りの9番目の項目を取り出した。

今回使用しているNginxのアクセスログでは、9番目の項目がHTTPステータスコードになっている。

```bash
awk '{print $9}' /var/log/nginx/access.log
```

さらに、取り出したステータスコードを`sort`で並べ替え、`uniq -c`で同じ値の出現回数を集計した。

```bash
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -nr
```

処理の流れは以下のようになる。

1. `awk '{print $9}'`：HTTPステータスコードだけを取り出す
2. `sort`：同じステータスコードを隣り合わせにする
3. `uniq -c`：同じステータスコードが何件あるか数える
4. `sort -nr`：件数が多い順に並べる

これにより、200、403、404などのHTTPステータスコードがそれぞれ何件記録されているかを集計できた。

### journalctlでNginxのサービスログを絞り込んだ

`journalctl`を使用して、systemdが管理しているログからNginxサービスに関する記録を取得した。

```bash
journalctl -u nginx --since "1 month ago"
```

さらに`grep`を組み合わせ、`start`、`stop`、`reload`のいずれかを含むログだけを抽出した。

```bash
journalctl -u nginx --since "1 month ago" | grep -i 'start\|stop\|reload'
```

`grep -i`を使用することで、大文字と小文字を区別せず検索した。

また、`grep -c`を組み合わせて、条件に一致するログの件数を数える練習も行った。

### Nginxの自動起動設定を確認した

以下のコマンドを使用して、NginxがOS起動時に自動起動する設定になっているかを確認した。

```bash
systemctl is-enabled nginx
```

結果は`enabled`だった。

ここでは、

* `active`：現在サービスが動作しているか
* `enabled`：OS起動時にサービスを自動起動する設定になっているか

は別の状態を表していることを学んだ。

`disable`による自動起動設定の変更については、次回以降に確認する。

## つまずいたこと

以下のようなコマンドを実行した。

```bash
grep '10.77.0.20' /var/log/nginx/access.log | grep ' 404 ' /var/log/nginx/access.log
```

最初の`grep`で`10.77.0.20`を含む行だけを抽出し、その結果をパイプ`|`で次の`grep`へ渡している。

しかし、2つ目の`grep`でも検索対象として`/var/log/nginx/access.log`を指定してしまった。

そのため、1つ目の`grep`から渡された結果を検索するのではなく、2つ目の`grep`が改めて`access.log`全体から404を検索する形になり、パイプでつないだ意味がなくなってしまった。

正しくは以下のようにする。

```bash
grep '10.77.0.20' /var/log/nginx/access.log | grep ' 404 '
```

この場合、

**access.log全体 → 10.77.0.20を含む行 → その中から404を含む行**

という順番で絞り込まれる。

今回のつまずきから、パイプ`|`は単にコマンドを連結する記号ではなく、**左側のコマンドの出力を右側のコマンドの標準入力として渡す仕組み**であることを理解した。
