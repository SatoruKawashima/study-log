### メモリの取得と判定

```bash
mem_available=$(free -m | awk '/Mem:/ {print $7}')

if [ "$mem_available" -lt 500 ]; then
    echo "WARNING: available memory is ${mem_available} MB"
else
    echo "Available memory: ${mem_available} MB"
fi
```

### load averageの取得と判定

```bash
load_1m=$(awk '{print $1}' /proc/loadavg)

if awk "BEGIN {exit !($load_1m >= 2.0)}"; then
    echo "WARNING: load average is $load_1m"
else
    echo "Load average: $load_1m"
fi
```

## 学んだこと

* `free -m`の結果から`awk`を使って必要な値だけを抜き出し、変数へ保存できることを学んだ。
* `if`文を使うことで、取得した値が設定した閾値を超えているかどうかを判定し、正常時と異常時で表示を分岐できることを確認した。
* 異常系のテストでは、実際にサーバーへ高い負荷をかけなくても、閾値を一時的に変更することで安全にWARNING側の動作を確認できる。
* `/proc/loadavg`から現在のload averageを取得できることを学んだ。
* `[ ... ]`で使う`-lt`や`-ge`は整数比較向けであり、小数であるload averageの比較にはそのまま使いにくいことを知った。
* `$var`と`${var}`はどちらも変数を展開する書き方で、`${var}`は変数名の範囲を明示したい場合に使える。
* `$(command)`は変数展開ではなく、コマンドを実行してその出力を利用する「コマンド置換」である。

## つまずいたこと
* `if [ ... ];`という条件書く際、`if [...]`のように[]内の空白を埋めてしまい、何度もエラーになった。
　*　[ ←コレ自体も一種のコマンド名なので、必ず空白が必要になる。 
* `mem_available=$(...)`を書く際に、`() `を`{}`にするなど記号のミスタイプで何度かエラーになった。
* `$`と`&`を打ち間違えることがあり、シェルでは記号1文字の違いでも正常に動作しなくなることを改めて感じた。
* `$xxxx`、`${xxxx}`、`$(...)`など見た目の似た記法が複数あり、最初は役割の違いが分かりにくかった。
