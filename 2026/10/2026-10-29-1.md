## Web Security Essentials

Webサービスを安全に運用するための基本的な考え方について学習した。

### Webアプリケーションの保護

- セキュアコーディング
- 入力検証とサニタイズ
- 適切なアクセスコントロール

### Webサーバーの保護

- ログの記録と保全
- WAFの利用
- CDNの利用

### ホストマシンの保護

- 最小権限での運用
- 不要なサービスの停止
- 使用していないポートの閉鎖
- 適切なアンチウイルスソフトの運用

### 共通して重要なこと

- 強力な認証管理
- 適切なパッチ適用

Webアプリケーションだけを守ればよいのではなく、WebサーバーやOSを含めて複数の層で防御する必要があることを確認した。

## Detecting Web Attacks

一般的なWeb攻撃と、それらを防御側からどのように検知するかについて学習した。

### 主な攻撃

クライアントサイド攻撃として、

- XSS
- CSRF
- Clickjacking

サーバーサイド攻撃として、

- SQL Injection
- Brute Force Attack
- Command Injection

などについて確認した。

### ログベースの検知

Webサーバーなどに記録されたログから、不審なリクエストや攻撃の兆候を探す方法について学習した。

一方で、ログに記録される情報には限界がある。

例えばGETリクエストではURLやQuery Parameterから攻撃内容を確認できる場合があるが、POSTリクエストでは本文の内容が通常のアクセスログに記録されず、ログだけでは攻撃内容を十分に確認できない場合があることを学んだ。

### ネットワークトラフィックからの検知

Wiresharkを利用し、実際のネットワークトラフィックからWeb攻撃を確認する方法について学習した。

ログ分析とは異なり、通信そのものを確認することで、ログには残らない情報を調査できる場合がある。

一方で、HTTPSなどで暗号化されている場合には内容を直接確認できないなど、それぞれの方法に長所と限界があることも確認した。

### Web Application Firewall

WAFの役割について学習した。

WAFではWebアプリケーションへのHTTP通信を検査し、ルールに一致する不審なリクエストを検知・遮断する。

演習では、WAFがどのような通信を対象としているかや、ルールベースの検知がどのような考え方で行われているかについて基礎を確認した。

## 所感

今回はWebセキュリティの基礎をまとめて学習した。

HTTPやWebアプリケーションの構造から始まり、Webサービスをどのように保護するか、さらに実際の攻撃をログ・ネットワークトラフィック・WAFからどのように検知するかまで、一連の流れを確認できた。

内容自体は基礎的なものが中心だったが、

**攻撃を知る  
→ どの層に痕跡が残るか考える  
→ ログや通信から検知する  
→ WAFなどで防御する**

というWebセキュリティ全体の流れを整理できた点が大きな学びだった。

また、ログだけですべてを確認できるわけではなく、必要に応じてネットワークトラフィックや他の情報源を組み合わせることが重要だと感じた。

## ひとこと
基本的には良く知っている内容だったが、知識の再確認という位置づけでは大事なステップだと思った。
