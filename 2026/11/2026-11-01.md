## Windows Threat Detection 1

Windows環境におけるInitial Accessと、その痕跡をWindows Event LogやSysmonから検出する方法について学習した。

主に、

- RDPなど公開サービスを利用した侵入
- ユーザー操作を起点とした攻撃
- 不審ファイルのダウンロード・実行
- 二重拡張子や`.com`などを利用したファイル偽装
- LNKファイルを利用した攻撃
- USB Drop Attack

などについて確認した。

RDP経由の侵入については、4624 / 4625などの認証イベントからログオン成功・失敗を追跡できる。

一方、ユーザー操作を起点とする攻撃では、Sysmonなどのプロセス実行ログを確認し、どのファイルがどこから実行されたのかを追うことが重要だと学んだ。

### 調査手順についての反省

演習ではZIPファイルを展開するべきか迷い、同じフォルダやアーカイブを何度も往復して時間を浪費した。

最終的にはLNKファイルを確認し、そのTargetからマルウェア配布URLを特定した。

今回の反省から、

**アーカイブを安全な分析環境で展開  
→ ファイル種別を確認  
→ LNKなど重要なArtifactの属性を直接調査  
→ IOCを抽出  
→ Sysmonログから実行・DNS・ファイル生成を追跡**

という流れを意識したい。

単に正解を見つけるだけでなく、調査の進め方そのものを効率化することもSOC業務では重要だと感じた。

## Windows Threat Detection 2

Initial Access後に攻撃者が行うDiscovery、Collection、Exfiltration、追加ツールの持ち込みについて学習した。

今回もWindows Event ViewerやSysmonを利用し、実際に疑似的な攻撃操作を実行しながら、どのような証跡が残るのかを確認した。

### Discovery

攻撃者は侵入後、まず被害端末やネットワーク環境について調査する。

例として、

- ユーザー情報
- 実行中のプロセス
- セキュリティ製品
- システム情報

などを確認するコマンドが利用されることを学んだ。

Discoveryは「被害環境を理解する」ことが目的であり、後述するCollectionとは目的が異なる。

### Collection

攻撃者が価値のある情報を探し、収集する活動について確認した。

対象としては、

- 保存された認証情報
- ブラウザに保存されたパスワード
- SSHキー
- 文書ファイル
- クリップボード情報

などが考えられる。

演習ではChrome Password Managerから保存済み資格情報を確認し、侵害後にブラウザ内の情報が攻撃者に利用される可能性を体験した。

### Exfiltration

収集した情報を外部へ持ち出す経路について学習した。

攻撃者は必ずしも露骨な不審サーバーを利用するとは限らず、

- Dropbox
- Mega
- Amazon S3
- GitHub
- Telegram
- 正規サービスに似せた独自ドメイン

など、一般的に利用されるサービスを持ち出し経路として悪用する可能性がある。

### Ingress Tool Transfer

攻撃者は最初からすべてのツールを用意して侵入するとは限らず、必要になった段階で追加のツールを取得することも学んだ。

演習では、

- Webブラウザ
- `certutil`
- PowerShell `Invoke-WebRequest`

など複数の方法でファイルをダウンロードし、それぞれどのようなログが残るか確認した。

## Windows Threat Detection 3

C2（Command and Control）、Persistence、Impactについて学習した。

これまでのInitial AccessやDiscoveryなどからさらに進み、攻撃者が侵害した端末へのアクセスをどのように維持するのかを確認した。

### Command and Control

攻撃者が侵害端末を継続的に操作するためのC2通信について学習した。

Sysmonやイベントログから、不審なプロセス実行や外部通信などを確認し、C2活動の兆候を探した。

### Persistence

攻撃者が再起動やログアウト後もアクセスを維持するための代表的な方法として、

- Scheduled Task
- Startup Folder
- Service
- Registry Run Key

などを確認した。

これらの変更についてもWindows Event LogやSysmonに証跡が残るため、それらを利用して永続化を検出する方法を学んだ。

### 検知について感じたこと

今回の演習では探すべき対象や、不審なファイル名などがある程度分かっていたため検出できた。

しかし、実環境では攻撃者が分かりやすい名前を利用するとは限らないため、「怪しい名前」を探すだけでは不十分である。

実際には、

- 通常とは異なる親子プロセス関係
- 不自然な外部通信
- 新規Scheduled Task
- Registry Run Keyの変更
- 不審なService作成

など、**正常な環境から外れた振る舞いを検出する必要がある**と感じた。

また、可能であればPersistenceやC2まで侵害を進ませる前に、Initial Accessの段階で検出・遮断することが最も望ましい。

一方でInitial Accessを完全に防ぐことは難しいため、攻撃ライフサイクルの各段階で検知できる多層防御が重要である。

## Active Directory Basics

Windows環境の理解を深めるため、Active Directoryの基礎について学習した。

主に、

- Active Directoryとは何か
- Domain
- OU
- Forest
- Domain Trust
- ユーザー・アカウント管理
- 権限委任
- Group Policy

などについて確認した。

演習では実際にAD上でユーザーを管理したほか、権限を委任したり、GPOを作成して複数のOUへリンクしたりした。

### 権限委任とGPO

操作そのものは比較的分かりやすかったが、権限やポリシーの適用範囲を正しく理解することが重要だと感じた。

演習中、特定ユーザーへの権限委任を意図していたところ、対象ユーザーが所属する部署全体に対してパスワードリセット権限を与えてしまうなど、スコープの指定でミスをした。

ADでは操作そのものは簡単でも、適用対象を誤ると影響範囲が大きくなるため、

**「何を設定するか」だけでなく「どこに適用されるか」**

を必ず確認する必要がある。

GPOについては、ポリシーを作成し、対象となるOUへリンクすることで、中央から複数ユーザーや端末へ設定を適用できる仕組みを確認した。

## 操作面での反省

今回の学習では、技術内容そのものとは別に、操作やトラブルシューティングで時間を浪費する場面が多かった。

### RDP環境

RDP接続した環境からさらにRDP接続する構成だったため、コピー＆ペーストが利用しにくく、長いPowerShellコマンドを手入力する必要があった。

その結果、

`Set-ADAccountPassword sophie -Reset -NewPassword (Read-Host -AsSecureString -Prompt 'New Password') -Verbose`

のような長いコマンドを何度も入力し直すことになった。

今後はTab補完などを利用し、ラボ環境の制約も事前に確認しておきたい。

### エラーログを読む

操作に失敗した際、

- 最初はコマンド入力ミス
- 次はPermission Denied
- その後はパスワードポリシー違反

と、失敗原因が途中で変わっていたにもかかわらず、同じ問題だと思い込んで何度も再試行してしまった。

パスワードについても、大文字・小文字・数字を含む8文字以上というポリシーを見落としていた。

今後は、

**同じ操作を繰り返す前に、必ずエラーメッセージやログを読む**

ことを意識したい。

単純なブルートフォース的試行ではなく、エラー内容から原因を切り分けて次の操作を決める必要がある。

## 所感

Windows Threat Detection 1～3を通じて、

**Initial Access  
→ Discovery  
→ Collection  
→ Exfiltration / Tool Transfer  
→ C2  
→ Persistence  
→ Impact**

というWindows環境における攻撃の流れを、Windows Event LogやSysmonを利用しながら一通り確認できた。

以前はWindows侵害調査で「どこを見ればよいのか」が分からず苦戦していたが、今回の一連の学習を通して、

**「攻撃者がこの行動をした場合、どのログやArtifactに痕跡が残る可能性があるか」**

という対応関係が少しずつ見えるようになってきた。

また、Active Directoryについても基礎的な管理操作を経験し、企業Windows環境におけるユーザー、権限、ポリシーの中央管理について理解を深めることができた。

次の職場ではWindows環境の監視が中心になる予定のため、今回の学習はちょうど良い一区切りになったと感じる。

現時点ですべてのEvent IDやコマンドを覚えているわけではないが、完全に暗記することよりも、

**「何を調べるために、どこを見るべきか」**

を判断できるようになることを今後の目標としたい。
