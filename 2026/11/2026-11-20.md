## Boogeyman 3

SOC Level 1最後の課題として、Elasticを利用し、PDFに偽装されたHTMLファイルを起点とする一連の攻撃を調査した。

### 初期侵入

まず、`file.extension=html`を条件にログを確認し、初期段階のペイロードを実行したプロセスのPIDを特定した。

PDFに見せかけたHTMLファイルから処理が開始されており、見た目だけでは正規ファイルと判断できないことを改めて確認した。

### 永続化

続いて、`review.dat`という不審なファイルがどのように配置され、永続化につながったのかを調査した。

単に不審ファイルを見つけるだけでなく、

**どのプロセスが生成したのか  
どこへ配置されたのか  
その後どのように利用されたのか**

を追跡することで、攻撃者が侵害状態を維持しようとしていたことを確認した。

### UACバイパス

攻撃者が権限を高めるため、`fodhelper.exe`を利用したUACバイパスを行っていたことを特定した。

今回はUACバイパスに関連する痕跡を広く検索し、その中から`fodhelper.exe`の利用へたどり着いた。

`fodhelper.exe`はWindowsの正規プログラムであるため、実行された事実だけでは悪性と判断できない。

周辺のプロセスやレジストリ変更など、実行コンテキストを確認する必要があると感じた。

### 認証情報窃取と横展開

その後、攻撃者がGitHubからMimikatzを取得していたことを確認した。

ログを追跡し、

- Mimikatzの取得
- 認証情報の窃取
- 取得した認証情報の利用
- 別ホストへの横展開

までの流れを確認した。

これまで個別に学習してきたCredential AccessやLateral Movementが、実際の攻撃チェーンとしてつながっていく様子を確認できた。

### 最終段階

最後に、侵害されたホストから攻撃者側のリソースへアクセスした痕跡を調査した。

その結果、攻撃者がランサムウェアをダウンロードしようとしていたことを確認した。

今回の調査では、

**初期侵入  
→ 永続化  
→ UACバイパス  
→ 認証情報窃取  
→ 横展開  
→ ランサムウェア取得**

という一連の攻撃をElastic上のログから追跡した。

## Senior Security Analyst Intro

SOC Level 1を終え、SOC Level 2の学習へ進んだ。

今回のRoomでは、Senior Security AnalystがJunior Analystとどのように異なるのか、またどのような責任が増えるのかについて学習した。

### エスカレーション範囲の拡大

Junior Analystでは主にSOC内部でのエスカレーションが中心となるが、Senior Analystでは、

- 他部署
- クライアント
- 外部のセキュリティチーム

など、SOC外の関係者と連携する機会も増える。

単にアラートを調査するだけでなく、調査結果を根拠とともに整理し、適切な相手へ伝える能力も求められる。

### Attacker Mindset

Senior Analystでは、表面的には正常に見える挙動についても、攻撃者がどのように悪用できるかを考える必要がある。

例えば、

- 正規のWindowsツールを利用したLiving Off the Land
- 一般的なコマンドを利用したWeb Shell
- 通常の管理操作に見える不審な処理

などを、単なる正常動作として見過ごさない視点が求められる。

そのためには、

**攻撃者がどのような手順で侵害を進めるのか**

を理解するAttacker Mindsetが重要になる。

攻撃手法を知っておくことで、単独では些細に見える兆候を、攻撃チェーンの一部として認識できる可能性が高くなる。

### 検知ルールの改善

SOC Level 2では、既存のアラートを処理するだけでなく、検知そのものの品質についても考える必要がある。

例えば、

- アラートが少なすぎる場合  
  → 検知ルールが適切に機能しているか確認する

- アラートが多すぎる場合  
  → 誤検知が多くないか確認し、ルール調整を検討する

といった対応が必要になる。

必要に応じてセキュリティチームと連携し、検知精度を改善することもSenior Analystの役割となる。

### 情報の要約と共有

Senior Analystは、Threat ReportやIncident Reportなどの情報を読み、その内容をJunior Analystが理解しやすい形に整理・共有する能力も求められる。

単に自分が理解するだけでなく、

**重要な部分を抽出し、他のAnalystが判断に利用できる形へ変換する**

ことも役割の一つである。

## 所感

今日はSOC Level 1最後の課題であるBoogeyman 3を完了し、そのままSOC Level 2の学習へ進んだ。

Boogeyman 3では、Elasticを利用して一連の攻撃チェーンを追跡した。

これまで個別に学習してきた、

- Persistence
- UAC Bypass
- Credential Access
- Lateral Movement
- Living Off the Land
- Ransomware

などの要素が、一つのIncidentの中で連続して発生することを確認できた。

また、Senior Security Analyst Introでは、SOC Level 2になると、

**「アラートを正しく処理する」だけでなく、  
「検知の質を考える」  
「攻撃者の視点で考える」  
「他のAnalystを支援する」**

という役割が増えることを学んだ。

SOC Level 1では主に、

**何を見るか  
どこを見るか  
どのログを使うか**

を学習してきた。

SOC Level 2では今後、

**なぜ疑うのか  
どこまで調査するのか  
どう判断するのか  
どう他者へ伝えるのか**

といった、より高度な分析や判断が求められそうだと感じた。
